# Piscinas Cascais

Site de construção, renovação e manutenção de piscinas na zona de Cascais.

## Páginas

- `index.html` — página principal
- `orcamento-construcao.html` — calculadora de orçamento de construção
- `orcamento-manutencao.html` — calculadora de orçamento de manutenção
- `images/` — fotografias usadas nas páginas

## Ver localmente

Abrir `index.html` no browser, ou no VS Code usar a extensão **Live Server**.
